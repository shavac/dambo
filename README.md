# dambo（弹宝） — AI 动力的直播插件平台

[简体中文](README.md) | [English](README.en.md)

**dambo（弹宝）** 是一款高性能、低资源占用的 B 站直播间交互与挂件工具，集 **AI 零基础定制插件**、**OBS 透明挂件 / 桌面置顶悬浮窗**、**弹幕采集与桌面快捷发弹幕**、**无损互动录制**与 **实时事件流**于一体，开箱即用。

**对话即可定制挂件：** 无需编程基础，将插件引导文档发给任意 AI（ChatGPT / Claude / Gemini / DeepSeek 等），回答 2 轮大白话选择题即可生成专属 OBS 挂件与桌面互动工具；**如果你对自己的表达能力有信心**，也可直接上传技术规范让 AI 严格照规范一步生成。放入 `static/html/` 后约 **200ms 自动热重载**，并自带可视化管理页实时调参。

## 核心功能与优势一览

- **节省资源、性能优异**
  - 基于 **Rust + Tokio + Tauri** 原生引擎与零构建依赖的纯 Web 挂件架构（无需额外 Node / Electron 运行时，内嵌异步事件整形与有界环形快照缓存），CPU 与内存占用极低，高并发弹幕刷屏或游戏同屏开播也流畅跟手。

- **桌面控制舱 & 系统托盘（`dambo-ui`）**
  - 紧凑无边框悬浮控制条，支持左侧拖动位置、右侧边缘拉伸宽度、**简体中文 / 日本語 / English** 实时切换与系统托盘快捷控制。
  - 支持 B 站手机 App **扫码登录**，一键切换 **我的直播间 / 关注开播中 / 历史房间** 或直接粘贴直播间链接。
- **控制舱弹幕聊天框**
  - 登录 B 站并进入直播间后，点击控制舱上的**弹幕输入按钮**即可在下方展开与控制栏等宽的输入框，随时直接向当前直播间发送弹幕。
- **OBS 透明挂件 & 桌面置顶悬浮窗**
  - 一键复制地址添加到 OBS Studio「浏览器」源，或直接在桌面以无边框透明置顶浮窗打开，边打游戏边看弹幕或玩互动挂件；插件目录变更后自动热重载，无需重启。
- **多端实时联动 & 跨插件通信（免自建后端）**
  - **控制端操作，全端秒级同步**：主播在管理页或桌面端改配置、抽签、计分、棋盘落子，所有打开的 OBS 浏览器源与桌面悬浮窗即时同步变化，无需刷新页面。
  - **插件之间还能“组队配合”**：宿主通过统一 SSE 通道直接提供强类型配置热更（`Dambo.config`）、持久化 KV（`Dambo.storage`）、内存高速状态（`Dambo.memory`）、一对多事件广播（`Dambo.topics`）与跨插件权限审批（`Dambo.acl`）；**做互动小游戏、联动积分榜或复杂场控面板，不必再单独写后端或搭 WebSocket 服务**。
- **开箱即用内置插件**
  - 自带透明弹幕流（带礼物 4 秒连击归并与置底跟随）、场控监看列表、SC/大航海倒计时卡片与 **扑克 24 点弹幕抢答游戏**。
- **全量无损事件录制 & 实时数据流**
  - 自动将每场直播的弹幕、礼物、醒目留言（SC）、大航海、进房/关注与上下播状态保存为 `.jsonl` 文件；支持无界面命令行模式（`dambo-cli`）与双 WebSocket 数据输出（`/ws`、`/ws/event`）。

## 快速上手使用

### 1. 启动 Dambo

- **直接下载发行版（推荐普通用户）**：从 Releases 下载对应平台的压缩包解压后，直接双击运行 **`dambo-ui`**（或 macOS 下的 `Dambo.app`），发行包已自带默认配置文件 `etc/config.toml` 与全部内置插件。
- **命令行 / 服务器无头运行**：在终端运行 **`dambo-cli`**，适合挂机录制或纯后端消费（支持 `-c` 指定配置、`-r` 指定房间号或链接、`--no-login` 跳过扫码、`--record-raw` 录制原始数据包）。

<details>
<summary>从源码运行与贡献说明（可选）</summary>

若需自行从源码运行（需 Rust 1.90+ 及 Tauri 桌面依赖）：

```bash
# 桌面控制舱
cargo run -p dambo-ui --release -- --config etc/config.toml

# 无头命令行模式
cargo run -p dambo-cli --release -- --config etc/config.toml
```

更多测试与提交约定请参见 [CONTRIBUTING.md](CONTRIBUTING.md)。

### 2. 登录账号与连接直播间

1. **扫码登录**：点击控制舱左侧的账号按钮（未登录时显示灰点与 **扫码登录**），使用哔哩哔哩手机 App 扫码确认即可完成登录（会话凭证本地保存在 `var/dambo.redb`）。
2. **连接直播间**：
   - 在输入框直接填入**房间号**、**短号**或 `https://live.bilibili.com/...` 直播间链接后按回车或点击 **进入**；
   - 或点击输入框右侧下拉箭头，直接从 **我的直播间**、**关注开播中**、**历史房间** 中一键选择。

### 3. 使用聊天框发送弹幕

当控制舱同时满足 **已扫码登录 B 站** 且 **已连接进入直播间** 时，控制栏上的 **弹幕气泡按钮** 会自动启用：

1. 点击弹幕按钮，控制舱正下方会平滑展开等宽的弹幕输入框（输入上限 `40` 字）。
2. 输入内容后按 **`Enter`** 或点击 **发送** 即可立即向当前直播间发出弹幕；发送后光标保留在输入框内，方便连续回复观众。
3. 切换去操作 OBS、游戏或其他窗口时输入框会保持展开不丢失；需要收起时，再次点击弹幕按钮、按下 **`Esc`**，或点击控制栏上的其他功能按钮即可恢复单行悬浮条。

> 未登录或尚未连接直播间时，弹幕按钮会处于禁用状态，鼠标悬停可查看当前缺失条件提示。

### 4. 在 OBS 或桌面中使用插件

在控制舱点击 **插件（...）**（或在系统托盘中展开 **插件** 菜单）：

- **接入 OBS Studio**：点击插件卡片上的 **复制 OBS URL**，在 OBS 来源中新建 **浏览器** 源，粘贴地址并设置所需宽高即可实现透明叠加。
- **桌面独立悬浮查看**：点击 **桌面打开**，插件会作为透明悬浮窗直接浮在屏幕上；将鼠标移到浮窗右上角可拖动位置、切换窗口置顶或关闭（也可用 `Esc` 关闭）。
- **局域网多端查看**：若想用同一 Wi-Fi 下的手机/平板打开监看面板（如 `/list/`），可在配置文件 `etc/config.toml` 的 `[server]` 下将 `host` 改为 `"0.0.0.0"`。

### 5. 插件管理界面（`/{插件名}/m`）

每个插件都拥有独立的管理页入口 `GET /{插件名}/m`，用于在浏览器中调整挂件参数与权限：

- **打开方式**：在控制舱 **插件** 菜单中点击对应插件的 **管理页** 按钮，或在系统托盘 **插件 -> 打开管理页** 选择对应插件，也可以直接在浏览器访问 `http://localhost:3838/{插件名}/m`。
- **自定义页与内置兜底控制台**：如果插件目录下提供了 `manage.html`（及可选 `manage.css` / `manage.js`），宿主会直接渲染自定义管理页面；若未提供（如内置插件与绝大多数 AI 生成插件），Dambo 会自动提供开箱即用的内置通用控制台，无需手写管理前端：
  - **配置参数热更新**：依据 `plugin.json` 的 `defaults` 自动生成表单，修改后立即持久化到 `var/dambo.redb` 并实时推送到 OBS / 桌面展示页生效（支持单字段或全部恢复默认）。
  - **跨插件权限审批（ACL）**：集中审批、调整或撤销其他插件对当前插件数据或私有订阅源的访问请求，并可查看对外发起的申请。
  - **订阅源（Topics）与存储浏览**：查看、切换或删除插件订阅源（公开 / 私有），以及按命名空间浏览、编辑持久化（`persist`）与内存态（`memory`）强类型键值。
- **访问与安全边界**：管理页默认通过本地浏览器导航自动签发 `HttpOnly`、`SameSite=Strict` 会话 Cookie 解锁，并禁止被 `iframe` 嵌入（`X-Frame-Options: DENY` / `CSP frame-ancestors 'none'`）；若将 `[server].host` 开放到局域网（如 `0.0.0.0`），需在 `etc/config.toml` 中配置 `[server].admin_token`，非本机浏览器会在管理页弹窗输入口令后解锁。

## 内置插件说明

Dambo 默认自带 4 款即开即用的网页插件：

| 插件 | 访问路径 | 适用场景与玩法 |
| --- | --- | --- |
| **`default`** | `/default/` | **主力透明弹幕挂件**：底部进房停靠栏、顶部 SC/大航海倒计时置顶条、礼物 4 秒滑动连击归并跳动与自动跟随置底（OBS 浏览器源示例：`http://localhost:3838/default/`） |
| **`list`** | `/list/` | **主播 / 场控监看列表**：支持按全部 / 弹幕 / 礼物与SC / 粉丝牌筛选，向上翻看历史时自动锁屏并统计未读数 |
| **`sc-ticker`** | `/sc-ticker/` | **SC 与大航海独立卡片**：仅聚焦展示醒目留言（SC）与上舰倒计时滚动条，适合单独摆放在画面角落 |
| **`game24`** | `/game24/` | **扑克 24 点弹幕抢答游戏**：每局随机发 4 张 A–K 扑克牌，观众在弹幕发算式（如 `(3+3)*(8-4)`）抢答计分并显示排行榜；默认单局 `300s`，支持 `?timeout=300&solvable_only=false&settle_time=3.5&skip_time=2.5` 参数定制 |

## 使用 AI 助手零基础制作插件

无需编写代码，只需两步即可让任意 AI（ChatGPT / Claude / Gemini / DeepSeek 等）为你生成可用插件——从简单的礼物进度条，到“管理页遥控、OBS 与桌面端实时联动”甚至跨插件共享数据的互动小游戏都能直接搞定（无需自写后端服务）：

1. **梳理想法**：下载本仓库的 [`docs/PLUGIN_GUIDE.md`](docs/PLUGIN_GUIDE.md)（[English](docs/PLUGIN_GUIDE.en.md)）上传给 AI，并用一句话描述你的初步想法（例如：*“我想做一个礼物电池目标进度条”*）。
2. **生成代码**：回答 AI 的 2 轮选择题确认细节后，按 AI 提示上传 [`docs/PLUGIN_SPEC.md`](docs/PLUGIN_SPEC.md)（[English](docs/PLUGIN_SPEC.en.md)）并回复 **`开始生成`**，将生成的文件夹放入 `static/html/` 即可使用。

**一步直达（适合表达清晰的进阶用法）**：如果你对自己的表达能力有信心，能够一次性把功能、样式和交互要求说清楚，也可以跳过第 1 步访谈，直接把 [`docs/PLUGIN_SPEC.md`](docs/PLUGIN_SPEC.md)（[English](docs/PLUGIN_SPEC.en.md)）上传给 AI，附上你的完整需求并明确要求：**“请严格依照上传的 `PLUGIN_SPEC` 规范实现我的需求”**。

> 在控制舱点击 **插件 -> 打开插件目录**（即 `static/html/`）放入插件文件夹（标准结构为 `plugin.html`、`plugin.json`、`plugin.css`、`plugin.js`，可选 `manage.html` / `manage.css` / `manage.js` 及同级静态资源），保存后约 200ms 自动识别上线，**无需重启 Dambo** 即可直接在桌面打开、访问管理页或复制到 OBS 使用。如需手动编写，也可直接查阅上述 [`docs/PLUGIN_SPEC.md`](docs/PLUGIN_SPEC.md) 技术规范。

## 录制、常用设置与实时接口

### 常见操作入口

在控制舱右侧点击 **`…`（更多操作）**（或右键系统托盘图标）：
- **窗口置顶**：让控制舱本身始终保持在最上层。
- **录制原始包（`*_raw.jsonl`）**：在默认无损事件记录之外额外保存原始下行数据包。
- **打开配置文件 / 录制目录 / 日志目录**：一键打开对应文件或目录，无需手动翻找路径。

### 配置与数据目录说明

- **`etc/config.toml`**（只读配置，从源码运行若不存在可从 [etc/config.sample.toml](etc/config.sample.toml) 复制）：
  - `[server]`：默认监听 `0.0.0.0:3838`，并默认启用 `security_mode = "open"`（局域网私网 IP 免密查看与自动放行跨插件读/订阅；切换为 `"strict"` 可开启零信任令牌防护）。
  - `[feed]`：控制快照保留条数、是否展示进房提醒（`show_enter`）及粉丝牌（`show_medal`）。
  - `[record]`：控制是否自动录制以及文件名模板（默认保存在 `var/records/dambo_{主播名}_YYYYMMDD_HHMMSS.jsonl`）。
- **`var/`**（运行期自动生成）：集中存放统一嵌入式数据库 `dambo.redb`（登录态、最近房间、语言偏好、录制开关及插件持久化/ACL/订阅源）、运行日志 `logs/` 与直播录制 `records/`。

### 实时数据与挂件访问地址

| 地址 | 用途说明 |
| --- | --- |
| `GET /` | 打开唯一统一控制面板（默认普通主播极简模式：直播间连接/发弹幕、插件 OBS 链接复制与设置抽屉；开启右上角「🛠️ 开发者视图」可查看实时概览、局域网二维码、ACL 审批与 KV/Topic 数据检视器） |
| `GET /admin` | 兼容入口（`301` 永久重定向至 `/`，保留 Query） |
| `GET /{插件名}/` | 直接在浏览器 / OBS「浏览器」源中打开对应挂件展示页（如 `http://localhost:3838/default/`） |
| `GET /{插件名}/m` | 在浏览器或 `/` 抽屉中打开插件配置、跨插件存储与 ACL 审批管理页 |
| `GET /sdk/dambo.js` | 内置零依赖纯 Web 插件 SDK |
| `GET /api/v1/*` | 插件平台 Layer 1 HTTP REST + SSE 接口 |
| `GET /ws` | 实时弹幕与挂件事件流 WebSocket（`Snapshot`、`Event`、`RoomState`） |
| `GET /ws/event` | 经流量整形、刷屏合并与礼物连击结算的批次流 WebSocket（适合接入机器人、TTS 与 AI 管线） |
